👥 ผู้เล่น

🏆 จบเกม!

📖 กติกาเกม

  1. คว่ำเบี้ยทั้งหมดลงแล้วผสมกันเป็นกองกลาง
  2. ผู้เล่น 5 คน จั่วเบี้ยคนละ 5 ใบ
  3. วางเบี้ยเริ่มต้น [ START | ผู้ส่งสาร ] ลงกลางวง
  4. รอบที่ 1 เป็นรอบทดลอง สามารถวางเบี้ยได้อย่างอิสระ
  5. เมื่อจบรอบทดลอง จะเข้าสู่การต่อกระบวนการสื่อสาร
  6. ลำดับปกติคือ ผู้ส่งสาร → การเข้ารหัส → ข่าวสาร/สื่อ → การถอดรหัส → ผู้รับสาร → การตอบสนอง → ผลสะท้อนกลับ
  7. เมื่อถึง ผลสะท้อนกลับ สามารถวนกลับไป ผู้ส่งสาร เพื่อเริ่มกระบวนการใหม่
  8. [ Noise | Noise ] เป็นเบี้ยทางตัน
  9. เมื่อปลายแถวเป็น Noise ผู้เล่นต้องจั่วจนกว่าจะพบ Noise | คำศัพท์อื่น เพื่อกำจัดสิ่งรบกวน
  10. ใครวางเบี้ยจนหมดมือก่อน เป็นผู้ชนะ
  11. ผู้ที่วางเบี้ยปิดลูป ผลสะท้อนกลับ → ผู้ส่งสาร ได้คะแนนพิเศษ
